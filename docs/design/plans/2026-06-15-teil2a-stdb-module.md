# Teil 2A — SpacetimeDB-Modul Implementation Plan


**Goal:** A self-hosted SpacetimeDB module (C#) that stores player accounts + opaque profile blobs and brokers lobbies (server browser), with `ctx.Sender`-based authorization and a disconnect hook that closes stale lobbies.

**Architecture:** One C# WASM module published to a local/VPS SpacetimeDB instance. Four tables (`account`, `profile`, `lobby`, `lobby_member`) + six reducers + a `ClientDisconnected` lifecycle reducer. The profile `blob` is opaque bytes (produced by Teil 1 `SerializeProfile`); the module never interprets it. This is sub-plan 2A of Teil 2 — Companion (2B) and DLL-glue (2C) follow and depend on this schema.

**Tech Stack:** SpacetimeDB self-hosted (`spacetime` CLI, Docker for prod), C# module (.NET 8 + `SpacetimeDB.Runtime`), tested via `spacetime` CLI against a local instance.

**Spec:** `docs/design/specs/2026-06-15-spacetimedb-backend-design.md` (Komponente 1).

**Testing reality:** No xUnit here — the module is tested by publishing to a **local** `spacetime start` instance and asserting table state with `spacetime sql` after `spacetime call`. Each task ends with a concrete CLI check.

**SDK note (read once):** The C# codegen creates the table accessor from the `[Table(Name=...)]` value (e.g. `ctx.Db.account`) and the index/PK accessor from the field name (e.g. `ctx.Db.account.Identity.Find(...)`). After the first `spacetime build`, glance at the generated bindings and match accessor casing exactly — it is deterministic from Name + field names, not a guess.

```csharp
using SpacetimeDB;

public static partial class Module
{
    [SpacetimeDB.Table(Name = "account", Public = true)]
    public partial struct Account
    {
        [SpacetimeDB.PrimaryKey]
        public Identity Identity;
        public string   DisplayName;
        public Timestamp CreatedAt;
    }

    [SpacetimeDB.Table(Name = "profile", Public = true)]
    public partial struct Profile
    {
        [SpacetimeDB.PrimaryKey]
        public Identity Identity;
        public byte[]   Blob;        // opaque Teil-1 SerializeProfile() bytes
        public uint     Version;
        public Timestamp UpdatedAt;
    }

    [SpacetimeDB.Table(Name = "lobby", Public = true)]
    public partial struct Lobby
    {
        [SpacetimeDB.PrimaryKey]
        [SpacetimeDB.AutoInc]
        public ulong    LobbyId;
        [SpacetimeDB.Index.BTree]
        public Identity HostIdentity;
        public string   HostAddr;     // "ip:port"
        public string   Name;
        public string   Status;       // "open" | "in_game" | "closed"
        public uint     MaxPlayers;
        public Timestamp CreatedAt;
    }

    [SpacetimeDB.Table(Name = "lobby_member", Public = true)]
    public partial struct LobbyMember
    {
        [SpacetimeDB.PrimaryKey]
        [SpacetimeDB.AutoInc]
        public ulong    Id;
        [SpacetimeDB.Index.BTree]
        public ulong    LobbyId;
        [SpacetimeDB.Index.BTree]
        public Identity MemberIdentity;
        public Timestamp JoinedAt;
    }
}
```

## Task 3: Account + profile reducers

**Files:**
- Modify: `lobby/server/Lib.cs`

- [ ] **Step 1: Add the reducers inside `Module`**

Add these methods inside the `Module` class:

```csharp
    [SpacetimeDB.Reducer]
    public static void RegisterAccount(ReducerContext ctx, string displayName)
    {
        var existing = ctx.Db.account.Identity.Find(ctx.Sender);
        if (existing is Account acc)
        {
            acc.DisplayName = displayName;
            ctx.Db.account.Identity.Update(acc);
        }
        else
        {
            ctx.Db.account.Insert(new Account
            {
                Identity    = ctx.Sender,
                DisplayName = displayName,
                CreatedAt   = ctx.Timestamp,
            });
        }
    }

    [SpacetimeDB.Reducer]
    public static void UpsertProfile(ReducerContext ctx, byte[] blob, uint version)
    {
        var existing = ctx.Db.profile.Identity.Find(ctx.Sender);
        if (existing is Profile p)
        {
            if (version <= p.Version) return;   // last-writer-wins by version
            p.Blob = blob;
            p.Version = version;
            p.UpdatedAt = ctx.Timestamp;
            ctx.Db.profile.Identity.Update(p);
        }
        else
        {
            ctx.Db.profile.Insert(new Profile
            {
                Identity  = ctx.Sender,
                Blob      = blob,
                Version   = version,
                UpdatedAt = ctx.Timestamp,
            });
        }
    }
```

- [ ] **Step 2: Publish and test via CLI**

Run:

Expected: the `SELECT` returns one row with `display_name = "TestPlayer"`. (`spacetime call` authenticates as your CLI identity, which becomes `ctx.Sender`.)

## Task 4: Lobby reducers

**Files:**
- Modify: `lobby/server/Lib.cs`

- [ ] **Step 1: Add the lobby reducers inside `Module`**

```csharp
    [SpacetimeDB.Reducer]
    public static void CreateLobby(ReducerContext ctx, string name, string hostAddr, uint maxPlayers)
    {
        ctx.Db.lobby.Insert(new Lobby
        {
            LobbyId      = 0,            // AutoInc assigns the real id
            HostIdentity = ctx.Sender,
            HostAddr     = hostAddr,
            Name         = name,
            Status       = "open",
            MaxPlayers   = maxPlayers,
            CreatedAt    = ctx.Timestamp,
        });
    }

    [SpacetimeDB.Reducer]
    public static void UpdateLobbyStatus(ReducerContext ctx, ulong lobbyId, string status)
    {
        var lobby = ctx.Db.lobby.LobbyId.Find(lobbyId)
            ?? throw new Exception("lobby not found");
        if (!lobby.HostIdentity.Equals(ctx.Sender))
            throw new Exception("only the host may change lobby status");
        lobby.Status = status;
        ctx.Db.lobby.LobbyId.Update(lobby);
    }

    [SpacetimeDB.Reducer]
    public static void JoinLobby(ReducerContext ctx, ulong lobbyId)
    {
        var lobby = ctx.Db.lobby.LobbyId.Find(lobbyId)
            ?? throw new Exception("lobby not found");
        if (lobby.Status != "open")
            throw new Exception("lobby not open");

        uint count = 0;
        foreach (var m in ctx.Db.lobby_member.LobbyId.Filter(lobbyId)) count++;
        if (count >= lobby.MaxPlayers)
            throw new Exception("lobby full");

        ctx.Db.lobby_member.Insert(new LobbyMember
        {
            Id             = 0,
            LobbyId        = lobbyId,
            MemberIdentity = ctx.Sender,
            JoinedAt       = ctx.Timestamp,
        });
    }

    [SpacetimeDB.Reducer]
    public static void LeaveLobby(ReducerContext ctx, ulong lobbyId)
    {
        foreach (var m in ctx.Db.lobby_member.LobbyId.Filter(lobbyId))
        {
            if (m.MemberIdentity.Equals(ctx.Sender))
                ctx.Db.lobby_member.Id.Delete(m.Id);
        }
    }
```

## Task 5: Close stale lobbies on host disconnect

**Files:**
- Modify: `lobby/server/Lib.cs`

- [ ] **Step 1: Add the ClientDisconnected lifecycle reducer**

```csharp
    [SpacetimeDB.Reducer(ReducerKind.ClientDisconnected)]
    public static void OnDisconnect(ReducerContext ctx)
    {
        // Close every lobby this identity hosts, and drop its members.
        foreach (var lobby in ctx.Db.lobby.HostIdentity.Filter(ctx.Sender))
        {
            foreach (var m in ctx.Db.lobby_member.LobbyId.Filter(lobby.LobbyId))
                ctx.Db.lobby_member.Id.Delete(m.Id);

            var closed = lobby;
            closed.Status = "closed";
            ctx.Db.lobby.LobbyId.Update(closed);
        }
    }
```

- [ ] **Step 2: Publish; verify it compiles and the existing data is intact**

Run:
```

spacetime sql pulsar-lobby "SELECT status FROM lobby"
```
Expected: publish succeeds (the disconnect reducer compiled). Disconnect-driven closing is exercised end-to-end in 2B when the Companion connects/disconnects as a real client; here we only verify the reducer builds and registers. (CLI calls don't open a persistent connection, so they can't trigger ClientDisconnected directly.)

## What 2B/2C will need from this (interface contract)

- DB name `pulsar-lobby`; reducers `RegisterAccount(displayName)`, `UpsertProfile(blob, version)`, `CreateLobby(name, hostAddr, maxPlayers)`, `UpdateLobbyStatus(lobbyId, status)`, `JoinLobby(lobbyId)`, `LeaveLobby(lobbyId)`.
- Tables `account`, `profile` (opaque `Blob`), `lobby` (subscribe for the server browser), `lobby_member`.
- The opaque `Blob` is exactly the bytes from Teil-1 `Pulsar::Profile::SerializeProfile()`; 2C writes/reads it via the handoff file, 2B uploads/downloads it via `UpsertProfile` / a `profile` subscription.
